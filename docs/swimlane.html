Entry points

Every way code execution starts. Each card lists the command, the file that runs, and what it produces. The Streamlit app is the user-facing path; the others are standalone demos and offline pipelines.

● Live chat app primary

The rep-facing UI. Calls the orchestrator on every chat input.

streamlit run app/streamlit_app.py

Entry: streamlit_app.py:main()
Produces: cited answer + provenance expander in browser

● Orchestrator demo

Runs all three sample questions through the full pipeline. Best terminal sanity check.

python -m app.orchestrator

Entry: orchestrator.py:_demo()
Produces: stdout — route, SQL, sources, answer per question

● Router smoke test

Cheapest sanity check — no Databricks required, only Claude auth.

python -m app.router

Entry: router.py:_demo()
Produces: 3 sample classifications with extracted filters

● SQL agent demo

Generates & executes one SELECT against the warehouse. Tests Databricks SQL auth.

python -m app.sql_agent

Entry: sql_agent.py:_demo()
Produces: SQL + rows for "revenue by product, NE"

● RAG agent demo

Three filter cases against Vector Search. Tests the filter-narrowing behavior.

python -m app.rag_agent

Entry: rag_agent.py:_demo()
Produces: top-K chunks (unfiltered vs product vs region)

● PDF ingestion

Local: read PDFs → extract text → tag with Haiku → write JSON.

python -m app.pdf_ingest

Entry: pdf_ingest.py:main()
Produces: data/support_corpus.json

● PDF generator

Render data/pdf_source.json into formatted PDFs via reportlab.

python -m scripts.build_synthetic_pdfs

Entry: build_synthetic_pdfs.py:main()
Produces: data/pdfs/*.pdf

Swimlane — end-to-end hybrid question

Sequence-diagram view. Each column is an actor; each horizontal arrow is a function call or service request, in time order top-to-bottom. The activity bars highlight when an actor is on the critical path. This shows the hybrid flow because it exercises every component — analytical-only or knowledge-only flows are subsets of this one (skip the RAG block or the SQL block respectively).

User UI Orchestrator Router SQL Agent RAG Agent Claude API Databricks Entry / Exit request response
Conditional segments. Steps 7–13 only run when decision.needs_sql is true (analytical or hybrid). Steps 14–17 only run when decision.needs_docs is true (knowledge or hybrid). Pure knowledge questions skip the SQL block entirely; pure analytical questions skip the RAG block. The synthesis call (19–20) always fires — but the context it sees changes based on which agents ran.

External services & libraries

What each module reaches outside the repo for. Subscription auth via claude login covers all Claude API access; Databricks PAT in .env covers both Databricks services.

Library / Service Type Used by What for
claude-agent-sdk Claude API router.py · sql_agent.py · orchestrator.py · pdf_ingest.py Haiku (routing, tagging) and Sonnet (SQL generation, synthesis). Subscription OAuth.
databricks-sql-connector Databricks sql_agent.py Execute generated SELECT against the Serverless SQL warehouse.
databricks-vectorsearch Databricks rag_agent.py (and ingestion notebook) Query the Vector Search index with metadata filters; create/sync index offline.
streamlit + pandas Python streamlit_app.py Chat UI + rendering result DataFrames in the provenance expander.
pymupdf (fitz) Python pdf_ingest.py Local PDF text extraction. Runs on laptop; never deployed.
reportlab Python scripts/build_synthetic_pdfs.py Render data/pdf_source.json into formatted PDFs.
python-dotenv Python config.py Load .env into os.environ on import.

Exit points

Where execution lands. Every code path terminates in one of these. The UI exit is the rep-facing one; the rest are CLI demos and offline pipelines.

● Rendered answer in the browser primary

The Streamlit UI displays the synthesized answer with inline citations, plus an expander showing the route, SQL, rows, and retrieved sources.

app/streamlit_app.py
└─ _render_assistant_block(result)

● stdout (CLI demos)

The _demo() functions in router, sql_agent, rag_agent, and orchestrator all print to stdout. UTF-8 forced for em-dash safety on Windows.

sys.stdout.reconfigure(encoding="utf-8")
print(...)

● Delta table write + VS index sync

The Databricks ingestion cell finishes by overwriting the corpus Delta table and triggering an asynchronous Vector Search index sync. Poll until ready.

workspace.pharma_copilot.support_corpus_chunks
└─ idx.sync()

● data/support_corpus.json

The local pdf_ingest.py pipeline ends by overwriting this JSON file. The Databricks notebook reads it via raw GitHub URL.

data/support_corpus.json
└─ list[{doc_id, title, doc_type, product, region, content}]

● data/pdfs/*.pdf

The PDF generator script exits after writing all PDFs from data/pdf_source.json.

data/pdfs/
├─ Oncorix_Field_Reference_Guide.pdf
├─ ImmunoShield_Access_Guide.pdf
└─ ...

● Raised exception (failure exit)

Hard failures bubble: missing env vars, broken Databricks creds, exhausted SQL retries. The UI catches these and renders an st.error block; CLI demos print a traceback.

# orchestrator.py
except Exception as e:
    st.error(f"Pipeline error: {e}")
